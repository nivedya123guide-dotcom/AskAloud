

# AskAloud 💬

### A classroom where every question deserves a voice.

AskAloud is a multilingual, voice-first classroom doubt platform designed to make learning more inclusive.

Students can ask questions in a language they are comfortable with, submit doubts without publicly speaking, and receive answers from their teacher.

## Problem

Many students hesitate to ask questions because of language barriers, fear of embarrassment, lack of confidence, or difficulty expressing themselves.

This can leave doubts unresolved and affect their learning.

## Solution

AskAloud provides a simple platform where students can:

- Ask doubts through voice or text.
- Use Malayalam, Hindi, or English.
- Submit questions anonymously.
- View their submitted doubts and teacher answers.
- Give feedback on whether an answer helped.

Teachers can:

- Create a classroom.
- Receive student doubts.
- View similar questions grouped together.
- Answer a group of common doubts.
- See student feedback.

## Running Locally

Install dependencies:

    pip install -r requirements.txt

Start the application:

    python app.py

Open:

    http://127.0.0.1:5000

## Important

AskAloud is a prototype created for demonstration.

Do not use real student names, sensitive personal information, or confidential classroom data.

Voice recognition depends on browser and device support. Translation may occasionally be inaccurate or unavailable.

The prototype currently uses a local JSON file for data storage. Data persistence and stronger authentication would need to be added before real-world deployment.

## Vision

AskAloud aims to make sure that language, confidence, and fear of speaking do not become barriers to learning.
